[สไลด์ 1]
Machine Learning เบื้องต้น
Machine Learning (ML) คือการให้คอมพิวเตอร์เรียนรู้รูปแบบจากข้อมูล แทนการเขียนกฎทุกข้อด้วยมือ
โมเดลเรียนรู้จากข้อมูลตัวอย่าง (training data) แล้วนำไปทำนายข้อมูลใหม่ที่ไม่เคยเห็น

[สไลด์ 2]
ประเภทของการเรียนรู้
- Supervised Learning: ข้อมูลมีคำตอบ (label) กำกับ เช่น ทำนายราคาบ้าน (regression), แยกอีเมลสแปม (classification)
- Unsupervised Learning: ข้อมูลไม่มี label ให้หาโครงสร้างเอง เช่น การจัดกลุ่มลูกค้า (clustering)
- Reinforcement Learning: agent เรียนรู้จากการลงมือทำและได้รางวัล/บทลงโทษ เช่น AI เล่นเกม

[สไลด์ 3]
การแบ่งข้อมูล Train / Validation / Test
- Training set ใช้สอนโมเดล
- Validation set ใช้ปรับ hyperparameter และเลือกโมเดล
- Test set ใช้วัดผลครั้งสุดท้าย ห้ามนำมาใช้ระหว่างการปรับโมเดล ไม่เช่นนั้นผลจะดูดีเกินจริง (data leakage)
อัตราส่วนที่พบบ่อย เช่น 70/15/15 หรือ 80/10/10

[สไลด์ 4]
Overfitting และ Underfitting
- Overfitting: โมเดลจำข้อมูลฝึกมากเกินไป ทำได้ดีมากบน training set แต่แย่บนข้อมูลใหม่
- Underfitting: โมเดลง่ายเกินไป ทำได้ไม่ดีทั้งบน training set และข้อมูลใหม่
วิธีลด overfitting: เพิ่มข้อมูล, ลดความซับซ้อนของโมเดล, regularization (เช่น L1/L2), dropout, early stopping

[สไลด์ 5]
การวัดผลโมเดล Classification
- Accuracy = จำนวนที่ทายถูก / จำนวนทั้งหมด (อาจหลอกตาเมื่อข้อมูลไม่สมดุล)
- Precision = TP / (TP + FP) — ในบรรดาที่ทายว่าเป็นบวก ถูกจริงกี่ส่วน
- Recall = TP / (TP + FN) — ในบรรดาที่เป็นบวกจริง ทายเจอได้กี่ส่วน
- F1-score = ค่าเฉลี่ยฮาร์มอนิกของ precision และ recall
ตัวอย่าง: การคัดกรองโรคมักเน้น recall สูง เพราะการพลาดผู้ป่วยจริง (FN) มีต้นทุนสูง

[สไลด์ 6]
Bias–Variance Tradeoff
- Bias สูง: โมเดลตั้งสมมติฐานง่ายเกินไป → underfitting
- Variance สูง: โมเดลไวต่อข้อมูลฝึกมากเกินไป → overfitting
เป้าหมายคือหาจุดสมดุลที่ทำให้ความผิดพลาดบนข้อมูลใหม่ต่ำที่สุด

[สไลด์ 7]
ขั้นตอนการทำโปรเจกต์ ML
1. นิยามปัญหาและตัวชี้วัด
2. เก็บและทำความสะอาดข้อมูล
3. สร้าง feature
4. เลือกและฝึกโมเดล
5. ประเมินผลด้วย validation set และ test set
6. นำไปใช้งานและติดตามผล (monitoring) เพราะข้อมูลจริงอาจเปลี่ยนไปตามเวลา (data drift)
